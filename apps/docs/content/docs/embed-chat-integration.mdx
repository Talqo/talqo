---
title: Embed and chat integration
description: Configure the widget for public end-user chat.
---

The embed token is public and visible in the host page. It cannot read a visitor's conversation. For a custom chat interface, use the [SDK](/sdk).

## Widget snippet

Place the generated widget snippet on your website:

```html
<script
	async
	src="https://your-widget-host/widget.js"
	data-talqo-embed-token="your-embed-token"
	data-talqo-api="https://your-talqo-api"
></script>
```

Keep `async`, so the widget never delays the host page's own content. Omit `data-talqo-api` when `widget.js` and the API share an origin.

## Chat behavior

Talqo sends the saved system prompt and completed conversation history with each message. It does not truncate or summarize history. Failed, cancelled, blocked, and interrupted replies are excluded from later model input.

## Limits and network identity

Chat limits apply per agent and visitor network, not per embed or conversation. Visitors sharing a network may share the same allowance. See [Deployment](/deployment) for limits and proxy configuration.

## Rotation, retention, and deletion

Rotating an embed token takes effect immediately. Update installed snippets at once. Existing chats lose access. Reassigning or deleting an embed also revokes its chats, but retains conversations and usage. These actions cannot cancel work already sent to the AI provider.

Talqo retains chat history and usage without automatic expiry, including after a visitor starts a new chat. Individual conversations cannot be deleted on their own. Deleting an agent permanently deletes its conversations and usage. Attached embeds must be deleted first.

Token usage includes the system prompt and conversation history on every model call. Some counts are estimates and may omit cancelled output or hidden reasoning. Do not use them to reconcile provider invoices.
