title: AI provider configuration
description: Connect text and embedding models to a self-hosted Talqo deployment.
---

Talqo requires your own provider credentials, one text model, and one embedding model. Embedded chats cannot reply until a text model is configured.

After you save a working configuration, new page loads pick it up within a minute. A chat a visitor already has open updates when they reload the page.

## Providers

Talqo supports OpenAI, Anthropic, Google Gemini, Mistral, Azure OpenAI, Amazon Bedrock, and OpenAI-compatible endpoints. Azure OpenAI and Amazon Bedrock accept static credentials or the API process's deployment identity. Anthropic provides text models only, so its text configuration requires a separate embedding provider.

## Model selection

Model suggestions do not distinguish text models from embedding models. Choose the correct type for each role. If suggestions are unavailable, enter the exact model identifier from your provider.

## OpenAI-compatible endpoints

OpenAI-compatible configuration accepts public, private, loopback, HTTP, and HTTPS base URLs for self-hosted inference. Anyone with **Configure AI** can therefore make the API process contact internal network addresses. Give a role with it only to trusted operators.
