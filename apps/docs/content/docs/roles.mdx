---
title: Roles and access
description: Decide what each person can see and change in the dashboard.
---

The first person to sign up during setup is the **admin** and has full access. Everyone else starts with the roles selected on their invitation, or with no access until assigned a role. A person with several roles has the combined access of those roles.

Access changes take effect when saved. Nobody needs to sign in again, but they may need to reload an open page.

## Invitations

Choosing roles on an invitation needs both **Manage users** and **Manage roles**. With only **Manage users**, you can invite members without access and ask someone with **Manage roles** to assign their roles later.

**Default** starts selected when you can assign it. It initially gives no access; edit it to set your usual starting access. You can deselect it, rename it, or delete it like any other role. If you delete it, no role starts selected. Leave all roles unchecked to invite someone without access.

Invitation links expire after seven days and work once. If a link no longer works, ask someone with **Manage users** and **Manage roles** to create a new invitation.

Deleting a role leaves invitation links usable, but they no longer give that role. If no roles remain on an invitation, the new member joins without access.

## You can only give what you have

You can manage or assign only roles whose access you have yourself. You can reset someone's password or remove them only if you have all their access. Only the admin can reset or remove the admin.

If you lose your own access to manage roles, someone else with **Manage roles** can give it back.
