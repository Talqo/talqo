## What this does

Every chat a visitor has with an agent is saved. Reading them shows you which questions come up, where the agent answers well, and where its instructions or documents need work.

Open **Conversations** in the sidebar. The newest conversations are at the top, grouped by day. Each row shows the visitor's first question, the time it started, which agent answered, and how many messages it has. Click a row to read the whole conversation.

Use **Agents** to see only some agents, and set **Show** to **Needs attention** to find conversations where a visitor did not get an answer because it failed, was blocked or broke off. Those rows are also marked **Needs attention**. Use **Previous** and **Next** to move between pages. The address in your browser keeps your filters and page, so you can bookmark it or send it to a colleague.

Only people with the **See conversations** permission can read conversations. See [Roles and access](/roles). Conversations are read-only: nothing you do here changes what the visitor sees.

## Answers that did not finish

Most answers are complete. A short note under an answer explains when one is not:

- **Still answering**: the agent was replying when you opened the page. Reload to see the rest. An answer that stops without finishing shows as interrupted instead.
- **Stopped: the answer contained a word from the word blacklist**: Talqo cut the answer off because it used a word from the agent's **Word blacklist**.
- **The visitor stopped this answer**: the visitor pressed stop.
- **The agent could not answer**: the AI provider failed. Check the AI provider settings if this happens often.
- **This answer was interrupted**: the server restarted or lost the reply partway through.

When an agent calls tools, the conversation shows the final answer but not what the tools returned.

## Privacy and retention

Conversations are kept until you delete the agent. Deleting an agent permanently deletes its conversations; this cannot be undone. Deleting an embed keeps the conversations that came through it.

Visitors may type personal details into the chat. Treat conversations as customer data and only give dashboard access to people who should see it.
